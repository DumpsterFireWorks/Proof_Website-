## Implementation rule

Before designing W1, Codex must inspect all five images locally and summarize the recurring visual characteristics it is carrying into the site: composition, typography direction, spacing, shape language, contrast, imagery/diagram style, and Proof brand treatment.

Do not infer the references from filenames.

## Preservation rule

- Do not delete, overwrite, compress, crop, recolor, or regenerate the originals.
- They are references by default, not automatically production assets.
- If a reference image itself should appear on the public site, Review-Control must confirm that use is appropriate and public-safe.
- Production assets derived from the references should live separately from the originals.

## Accessibility rule

The website must use text, hierarchy, shape/iconography, and sufficient contrast so important meaning never depends on color alone.
