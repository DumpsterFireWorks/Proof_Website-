# Research

Cross-project research and reusable lessons from this project are cataloged in the central private research library:

**`DumpsterFireWorks/Projects-research--library-`**

The library is the discovery index for reusable product, web, UX, architecture, experiment, audit, and evidence-backed findings across projects.

This repository remains authoritative for current code/status and original artifacts. Original source paths and commits remain authoritative provenance. Cataloging research in the library does not activate implementation here.

Before archiving or deleting this repository or any research-bearing branch, issue, PR, experiment, or document, verify that reusable research has been cataloged in the library. Do not move credentials, private runtime data, or sensitive evidence into it.
