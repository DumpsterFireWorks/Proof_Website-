# Proof Website Asset Intake

Drop the raw contents of the branding / website asset ZIP into this folder exactly as received.

## Intake rule

- Do not rename, resize, recompress, crop, recolor, or reorganize files before upload.
- Preserve any nested folders from the ZIP when practical.
- Duplicate/alternate versions are welcome; they will be reviewed before anything is promoted into the live site.
- Nothing in this folder is a production asset merely because it was uploaded here.

## After intake

The website maintainer will:

1. inventory and visually inspect every asset;
2. identify master Proof, product logos, icons, hero artwork, diagrams, and alternates;
3. preserve originals;
4. normalize production filenames and organize approved assets under `public/brand/`;
5. wire the approved assets into the site on a separate reviewed change;
6. run desktop/tablet/phone visual QA before merge.

This branch is intentionally isolated from `main` so raw intake cannot affect production.
