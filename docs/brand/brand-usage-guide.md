# PROOF Brand Asset Usage Guide

## Master brand

`PROOF` is the master brand. The master mark contains only the P/check emblem and the PROOF wordmark. **Do not append “Infrastructure” to the master logo.**

Files:
- `master/proof-master-transparent.png` — canonical transparent raster.
- `master/proof-master.svg` — traced vector counterpart for scalable production use.

## Product-family lockup

Every product uses the same family DNA: the same P/check emblem, the same PROOF wordmark, the same proportions, and an electric-blue subordinate product name. Only the subordinate name changes.

Approved family:
- PROOF DEPLOY
- PROOF ROOM
- PROOF CLOUD
- PROOF CORE
- PROOF BASE
- PROOF CONTROL
- PROOF CLOUD APP
- PROOF QUOTE
- PROOF FLOW
- PROOF OS

`PROOF OS` ends at **OS**. Do not add “Business Tools” or any other descriptor to the logo.

## Color and backgrounds

The system uses deep Proof navy and electric Proof blue. Transparent PNGs are intended to sit on white, pale surfaces, navy, glass, or gradient treatments without a white box. Preserve clear space around the mark; do not stretch, skew, recolor, or add product-specific decorative symbols.

## Ecosystem hero

`hero/proof-ecosystem-hero.png` communicates the intended architecture at a high level:

**SOURCE → DEPLOY → CLOUD → CORE**

BASE is shown as optional structured data. CONTROL is shown as an observation layer using the approved wording **“Ecosystem visibility.”** Control should not be described as replacing the authority of Deploy, Cloud, Core, or other underlying products.

## Infrastructure artwork

`infrastructure/proof-infrastructure.png` is **architecture / visual reference artwork**. Labels inside that artwork reflect the architecture language at the time it was created and are not automatically authoritative current website copy. Use it selectively. Do not rewrite product meaning merely to match old labels in the graphic.

## Product icons

Do not create a separate decorative SaaS icon family. The P/check emblem is the primary Proof family identifier. Normal functional interface glyphs are appropriate inside real products and technical diagrams when they serve a functional purpose.

## Product screenshots

Use **real product screenshots only**. Do not fabricate dashboards, customer data, deployment status, or conceptual software screenshots and present them as real. Approved screenshot candidates, when real captures are available, include Proof Room, Proof Deploy, Proof Flow, Proof Cloud App, and Proof Control.

No product screenshots are included in this package because this handoff is the brand-asset package, not a fabricated UI package.
